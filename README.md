<h1>TSAstream</h1>
<p>TSAstream is a python CLI program that lets you key in your scores and compare from term to term and you can also use it to compare other people</p>
<p>There is also a section where you can key in how many people got into which class</p>

<h2>Installation</h2>
<p>To install, you can click on the install.sh if you are on Linux or install.bat if you are on Windows</p>
<p>As the install scripts were newly implemented and might not be stable, you can input these following commands:</p>
<br>
<h3>For Linux:</h3><p></p>
Fedora/RHEL/CentOS based: `sudo dnf install python3`<br>`pip install numpy` <br> `pip install matplotlib`
Debian/Ubuntu based: `sudo apt install python3`<br>`pip install numpy` <br> `pip install matplotlib`
Arch based: `sudo pacman -S install python3`<br>`pip install numpy` <br> `pip install matplotlib`

<h3>For Windows:</h3><p></p>
`winget install -e --id Python.Python.3`<br>`pip install numpy` <br> `pip install matplotlib`

Finally check the version before running the script as this code needs Python 3.10 or above:
`python --version`

to run your script, simply click on the program if you are on Windows or use this command `python3 main.py` if you are on Linux. Don't forget to go into the right folder. It may be listed as TSAstream-zilelai or simply TSAstream.
